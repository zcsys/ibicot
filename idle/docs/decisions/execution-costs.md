## Operating usage model

No funded provider or account has been selected. Model usage independently of a quote so an actual current quote can later be applied without inventing a bill. Variables below are planning inputs, not measured production traffic.

| Variable | Meaning | Illustrative prelaunch scenario |
|---|---|---|
| I | Eligible cohort starts | 500, matching study planning target |
| S | Observed sessions | 10,000, matching stability planning target |
| e | Batched telemetry events/session | 20; tune against the approved minimal event catalogue |
| b | Compressed bytes/event | 600-byte planning allowance; measure actual payloads before launch |
| c | Cloud checkpoints/session for opted-in players | 2; lifecycle batching, no per-tick network save |
| u | Cloud opt-in share | 0.5 illustrative assumption, not conversion evidence |
| z | Compressed save bytes | 65,536-byte planning allowance; measure growing claim ledgers |
| R | Purchased receipt verifications/refunds | Measured store events; no assumed conversion |
| D | Retained raw telemetry days | Must be frozen in the actual privacy/operating policy |

For the illustrative cohort, event ingestion is S×e = 200,000 events and S×e×b = 120 MB decimal before indexing/replication; cloud writes are S×u×c = 10,000 with 655.36 MB transferred at the provisional save size. With two active save copies per opted-in install, I×u×2×z = 32.768 MB live save storage before backups. These are capacity estimates; storage retention, indexes, backup copies, reads, auth traffic and network overhead add to them. No provider free tier is assumed.

Monthly service cash = fixed hosting + event ingestion×quoted unit price + database reads/writes×quoted unit prices + retained GB-month×quoted storage price + transferred GB×quoted egress price + receipt/auth work×quoted unit cost + monitoring/backup costs. Keep authoritative ownership/claim transactions separate from optional telemetry. Local guest saving and free-route progress must survive analytics or cloud outages.

Track actual AI/account usage through the account's usage records; no per-agent dollar estimate is inferred from a human studio salary.
