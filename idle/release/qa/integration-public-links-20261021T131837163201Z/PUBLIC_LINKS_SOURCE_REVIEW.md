Scope: local S27 plumbing only. Source was copied before and after the lead's model repair. No Flutter, native, network or browser command was run. Hosted URLs, public operator/policy and browser account-deletion endpoint remain absent and unqualified.

It also allowed encoded control/backslash path bytes. `model-probe.log` preserves those actual Dart results. This was an exact-configuration contract mismatch, not evidence of a credential leak or remote redirect. The lead added canonical-string equality and encoded-control rejection. The unchanged original probe now rejects all normalization counterexamples; 26 independent desired-behavior assertions pass in `repaired/assertions.log`. Ordinary canonical HTTPS paths are preserved exactly, partial invalid configuration remains absent, and default build configuration is empty.

Source review found explicit user-click-only `LaunchMode.externalApplication`, no appended account/save/credential values, no mutation of game state, caught platform exceptions without raw details, a retryable failure notice, a single in-flight launcher guard, mounted-state handling, and forwarding of all existing Help callbacks and route configuration. Configured and unconfigured destinations are presented separately. The exact URL is selectable and not pseudolocalized.
