# Google icon export format

23October2026 primary-source review: https://support.google.com/googleplay/android-developer/answer/9866151?hl=en explicitly requires the store app icon to be32-bit PNG(with alpha),512×512,maximum1024KB; feature graphic uses24-bit PNG(no alpha),1024×500. Existing icon output is RGB24-bit. Change only the code-authored geometry renderer to export an RGBA icon with fully opaque alpha and identical RGB pixels; keep feature output RGB and byte-identical. Preserve original reviewed artifacts, manifests and reports. No native icon catalogue, game asset, geometry or font changes; this is a deterministic export encoding repair, not new art. Author and independent checks must inspect actual PNG header/mode/dimensions/bytes/alpha and old-versus-new RGB equality. Actual platform ingestion remains external.
