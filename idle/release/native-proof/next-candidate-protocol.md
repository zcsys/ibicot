## Immutable input and export gate

Capture the source once the final help integration and independent reviews are stable. Record the new fingerprint and archive, then allow working-tree implementation to resume. Run candidate-specific analysis/tests for core, persistence, progression, events, platform, simulation, mobile, Python services and native tooling. Preserve every failure against its original candidate. Production repairs require another declared candidate; test-only harness repairs remain separately hashed.

Export debug iOS simulator, Android APK and internal macOS bundles, then unsigned iOS device and Android AAB artifacts from the same immutable source. Android release registration is generated by the pinned SDK. Record all build results, hashes, lockfile comparisons and unsigned-signature checks. Compare production source before and after every runtime probe, including native Kotlin/Swift entrypoints, privacy manifests and dependency locks.
